# ChatGPT / GPT-4 归档

本目录合并自 [LLM-Paper-Lists](https://github.com/ArronAI007/LLM-Paper-Lists) 仓库，整理了 ChatGPT、GPT-4 发布前后（2023 年初）的论文、官方技术文档、技术解读博客及媒体报道归档，作为 AGI/LLM 发展历程的历史资料留存。

## 目录说明

- [论文与资料汇总](paper-list.md)：涵盖 AGI/LLM 综述、代码生成、ChatGPT 应用与工具等分类的论文、代码、博客链接列表
- [papers/](papers/README.md)：ChatGPT 相关论文列表（技术原理、评测、应用等分类）
- [official-docs/](official-docs)：OpenAI 官方发布的 GPT-4 System Card、GPT-4 Technical Report（中英文版）
- [gpt4-blog/](gpt4-blog)：GPT-4 技术细节解读、技术摘要、研究溯源等博客整理
- [chatgpt-blog/technology/](chatgpt-blog/technology)：ChatGPT 技术原理、复现经验、涌现能力、预训练指南等技术解读
- [chatgpt-blog/media-digest/](chatgpt-blog/media-digest)：机器之心、量子位、新智元等 2023 年初 ChatGPT/GPT-4 相关报道摘编（按媒体账号分文件，按日期归档）
- [articles/](articles)：OpenAI 团队介绍、AGI 路线图、GPT-4 与 ChatGPT 对比等独立文章
